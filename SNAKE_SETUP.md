# 🐍 Snake Animation Setup Guide

## Как активировать змейку:

1. **Перейдите в ваш репозиторий** на GitHub
2. **Откройте вкладку "Actions"**
3. **Найдите workflow "Generate Epic Snake Animation"**
4. **Нажмите "Run workflow"** (кнопка справа)
5. **Подождите несколько минут** - змейка сгенерируется автоматически

## Альтернативный способ:

Если змейка не появляется, можно использовать внешний сервис:

```markdown
![Snake Animation](https://github.com/Andrey2211553/Andrey2211553/blob/output/github-contribution-grid-snake-dark.svg)
```

## Цвета змейки:

- **Основной цвет**: `#8B5CF6` (фиолетовый)
- **Обводка**: `#7C3AED` (темно-фиолетовый)

## Частота обновления:

Змейка обновляется каждые 4 часа автоматически.

---

**Примечание**: Змейка показывает вашу активность на GitHub в виде анимированной змейки, которая "съедает" ваши коммиты! 🐍✨
