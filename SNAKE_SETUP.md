## 🚀 Как активировать змейку:

1. **Перейдите в ваш репозиторий** на GitHub
2. **Откройте вкладку "Actions"**
3. **Найдите workflow "Generate Epic Snake Animation"**
4. **Нажмите "Run workflow"** (кнопка справа)
5. **Подождите 2-3 минуты** - змейка сгенерируется автоматически
